# Portfolio

Personal web development portfolio built with Next.js and TypeScript.

## About

This is my personal portfolio website where I showcase web development projects and technical work.

The portfolio includes custom websites, landing pages, commercial storefronts and technical tasks.

The website supports both English and Russian languages.

## Projects

- Dvizh-Ufa - custom website for a youth event community
- Commercial landing pages and storefronts
- Technical tasks, website support and automation

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Vercel

- Responsive layout
- English and Russian language support
- Separate pages for projects
- Reusable UI components
- Animated interface elements
